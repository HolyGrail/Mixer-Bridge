# Mixer Bridge

音声ミキサーの計測値を外部に出力し、外部からの操作を受け付ける OBS Studio 用プラグイン（サードパーティ製）。

- マスターとソース別のラウドネス（EBU R128）を計測し、ローカル通信で外部プロセスへ送る
- 外部プロセスからの要求で、ソースのフェーダーとフィルタを操作する
- UI は持たない

開発中のため、まだ動作するコードはありません。

## 通信仕様

`docs/protocol.md` で公開する予定です（メッセージ定義とバージョン）。仕様だけを見て書いた最小クライアントを `examples/` に置きます。
